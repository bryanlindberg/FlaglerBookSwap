# 📚 FlaglerBookSwap

A web application for Flagler College students to easily swap books. Built with ASP.NET (C#), using MVC architecture, and a clean front end for managing book listings and users.

---

## 🔍 Overview

FlaglerBookSwap is designed to help flagler students exchange textbooks and reading material. Users can list books they want to give away or swap, search what others have listed, and arrange swaps — all via a simple, responsive web interface.

---

## 🛠 Project Structure

Here’s a high-level overview of how the code is organized:

| Folder | Purpose |
|---|---|
| `Data` | Database context, migrations, seed data etc. |
| `Models` | Domain models representing Books, Users, etc. |
| `Pages` / `Views` | UI layer: Razor Pages / Views for rendering web pages. |
| `ViewModels` | Models shaped specifically for passing data to the Views. |
| `wwwroot` | Static assets: CSS, JavaScript, images, etc. |
| `Properties` | Project metadata. |
| `Program.cs` & `FlaglerBookSwap.csproj` | App startup and configuration. |

---

## ⚙️ Features

- User registration and authentication  
- CRUD operations for book listings (create, read, update, delete)  
- Search or filter books by title, author, etc.  
- Responsive front end so the site works on desktop & mobile
